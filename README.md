## 🚢 Current Projects

### 1. Titanic Survival Prediction

**Location**: `titanic/`

**Description**: A machine learning project that predicts passenger survival on the RMS Titanic using logistic regression. This project demonstrates fundamental data science workflows including data preprocessing, feature engineering, model training, and prediction.

**Key Features**:
- Binary classification using logistic regression
- Comprehensive data cleaning and preprocessing
- Feature selection and categorical encoding
- Model validation and evaluation
- Submission-ready predictions

**Technologies Used**:
- Python
- pandas (data manipulation)
- scikit-learn (machine learning)
- Jupyter Notebook (analysis and visualization)

**Quick Start**:
```bash
cd titanic/
jupyter notebook codejup-1.ipynb
```

For detailed information about this project, see the [Titanic Project README](titanic/README.md).
